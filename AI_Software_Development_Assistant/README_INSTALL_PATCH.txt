# DevPilot AI - Patch Engineering Intelligence

Giải nén NỘI DUNG ZIP vào thư mục gốc của dự án hiện tại, ví dụ `AI_Software_Development_Assistant/`, chọn Replace khi trùng tên.
Giữ nguyên các `.env` đã cấu hình và sao lưu database trước khi cập nhật.
Bắt buộc khởi động lại AI service, Spring Boot, frontend.
Đặt DB_DDL_AUTO=update cho lần khởi động để Hibernate thêm các bảng AI mới.
Đọc docs/ENGINEERING_INTELLIGENCE.md để biết chi tiết API, quyền truy cập và cách demo.
Bản vá chứa FILE ĐÃ SỬA và FILE MỚI, không gồm các file source không đổi hay thư viện cài đặt.
